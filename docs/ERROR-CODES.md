# 错误码与前端处置

错误码是界面与后端之间的唯一约定。后端恒回 HTTP 200，错误在 body 的 `code` 里；
前端按 `code` 分流。本文是这张表的唯一落点——码的定义在 `backend/pkg/errors.go`，
两处必须同步。

## 段位

| 段 | 域 | 谁会失败 |
|---|---|---|
| 1xxx | 本地环境（内部 / 路径 / Git） | 我们自己跑的东西：Git 命令、路径校验 |
| 2xxx | 启动与装配 | 数据目录、设置写入、端口占用 |
| 3xxx | 引擎进程与协议 | 引擎没起、超时、协议不认、命令被拒 |
| 4xxx | 模型与凭据 | 模型不存在、登录失败 |
| 5xxx | 技能 / 插件 / 引擎配置 | frontmatter 不合法、目录只读、插件命令失败、配置读不了 |
| 6xxx | 会话 | 会话文件坏了、会话正被占用 |
| 7xxx | 入参与鉴权 | 参数不合法、令牌不对、来源不对 |
| 8xxx | 文件 / 路径 / 网络 | 路径不存在、网络失败、装卸命令跑失败 |
| 9xxx | 引擎自身的装 / 升 / 卸 | 缺包管理器、命令不存在、同一应用有长任务 |

**一个码只有一个意思。** 同一个码在界面里必须给同一种反应，而那要求码唯一。
两处不同的事用同一个码（比如「文件被占用」与「非本机来源」），界面就没法分流，
只能猜——猜错的表现是给用户一个与实际问题无关的提示。

## 前端处置表

**同一个码在整个界面里必须给同一种反应。**

| 码 | 界面应该做什么 |
|---|---|
| `1001` | 轻提示「出了点问题」，同时把详情写进日志抽屉。不弹窗。 |
| `1003` 工作目录不合法 | 轻提示 + 「重新选择目录」。字段旁内联错误。 |
| `1004` 路径越出工作目录 | 轻提示「只能操作工作目录里的文件」。不弹窗。 |
| `1005` 文件不存在 | 轻提示 + 「刷新」。用户可能刚在终端里删了它。 |
| `1007` 删除未跟踪文件失败 | 轻提示 + 原文（多半是被编辑器占用）。 |
| `1014` Git 命令超时 | 轻提示「仓库太大或 Git 卡住了」，不清空当前列表。 |
| `1015` 没装 Git / 不是仓库 | 工作区页显示原因原文 + 「初始化仓库」按钮（不是仓库时）。 |
| `1016` 提交信息没填或太长 | 提交框内联错误，输入框聚焦，不发请求。 |
| `1017` 没有可提交的改动 | 轻提示。提交按钮此时本来就是禁用的，出现即说明状态不同步。 |
| `1018` Git 入参不合法 | 表单内联错误（分支名 / 远端名 / 强制推送级别）。 |
| `1019` Git 拒绝了这次操作 | 轻提示 + 原文（钩子拒绝 / 工作区有改动 / 分支删不掉）。 |
| `1020` Git 身份没配 | 轻提示 + 「去终端配好 user.name 与 user.email」。 |
| `1021` 还有冲突没解决 | 顶部横幅 + 「标记已解决」。按钮不自动跳走。 |
| `1022` 远端目标不明确 | 轻提示 + 列出可选远端 / 让用户勾「建立上游」。 |
| `1023` 没有配置远端 | 轻提示 + 「添加远端」。 |
| `1024` 推送被拒 | 轻提示 + 原文。**绝不自动升级成强制推送**。 |
| `1025` 远端拒绝身份验证 | 轻提示 + 「检查凭据 / 用 SSH 密钥」。 |
| `1026` 连不上远端 | 轻提示 + 「检查网络或远端地址」。 |
| `1027` 带租约的强制推送被拒 | 轻提示 + 「先拉取再推」。 |
| `2001` 启动装配失败 | 整屏 `StartupError`，带「重试」与「打开日志」。别的都不可用。 |
| `2002` 数据目录不可写 | 整屏 `StartupError`，提示换一个可写目录或检查磁盘。 |
| `2003` 设置写入失败（注册表 / 启动项） | 轻提示「该偏好没保存成功」，开关拨回原位。 |
| `3001` 引擎没找到 / 没跑 | 输入框禁用 + 一段横幅（一句话 + 可复制安装命令 + 「重新检测」）。**不弹窗**。 |
| `3002` 引擎忙（正在跑一轮） | 轻提示「这一轮还没跑完」+ 禁用发送。 |
| `3003` 命令超时 | loading 结束 + 轻提示「这次操作超时」，不清空用户输入。 |
| `3004` 帧解析失败 | 页头连接灯变红 + 轻提示，提示引擎版本可能不兼容。 |
| `3006` 引擎不支持该能力 | **不该出现**。出现即说明前端没查 `caps`——记日志，界面静默隐藏入口。 |
| `4001` 模型不存在 | 下拉框标红该行，提示「这个模型引擎不认识，检查 models 配置」。 |
| `4003` 登录失败 | 登录卡片内联错误 + 原文；不关闭卡片。 |
| `5002` 技能文件不可解析 | 该行标灰 + 悬停显示原因；不要整页失败。 |
| `5003` 技能目录不可写 | 轻提示 + 「以只读方式查看」；开关拨回原位。 |
| `5004` 插件命令失败 | 该行标红 + 原文输出抽屉；列表不被清空。 |
| `5005` 引擎配置读不到 | 该区域显示「还没生成过」或原文；不要整页失败。 |
| `5006` 引擎配置解析不了 | 该行标灰 + 原文输出；不要猜测着写回。 |
| `6001` 会话文件损坏 | 该行标灰，可删除；不要整页失败。 |
| `6002` 会话正被占用 | 轻提示「这个会话正在别的窗口里跑」，禁用删除/改名。 |
| `6003` 会话删除失败 | 轻提示原话（多为文件被占用）；列表保持原状，可重试。 |
| `7001` 入参不合法 | 表单内联错误。 |
| `7002` 令牌无效 | 重连一次；仍失败则提示「请重启应用」。 |
| `7003` 请求不是来自本机 | 不提示用户（他不是攻击者，是配置错了）：记日志，拒绝响应。 |
| `8001` 路径不存在 | 轻提示 + 「重新选择」。 |
| `8003` 网络请求失败 | 轻提示 + 「检查网络或代理」。 |
| `8004` 装 / 升 / 卸的命令跑失败 | 该行标红 + 原文输出抽屉；列表不被清空。 |
| `9001` 缺包管理器 / 命令不存在 | **按钮不发出请求前就已禁用**，附一句缺什么 + 可复制的命令原文。出现即说明前端的 `can_*` 没生效。 |
| `9002` 该应用已有长任务在跑 | 该行按钮进 loading 并禁用，行内提示「还有一个任务在跑」。不弹窗。 |

三条纪律：

1. **错误必须带下一步**。不是「失败了」，而是「连不上引擎：检查是否装好了」。
2. **`detail` 只进日志，不进界面**。界面上永远只显示 `message`。
3. **不要用一个泛化码兜所有失败**。宁可加一个码，也不要让用户面对「操作失败」。

## 新增一个码

1. 在 `backend/pkg/errors.go` 里加常量，落在对应段位。
2. 在**产生它的那一处**用它，不要为了「统一」把不同的事塞进同一个码。
3. 在本文的「前端处置表」与「码表」里各加一行，写清界面该给什么反应。
4. 前端按 `code` 分流的地方同步（`frontend/src/api/http.ts` 只做统一拦截，
   具体分流在组件里）。

改一个码的含义等于改响应形态，必须 `ContractVersion` +1 并同步
`frontend/src/types/api.ts`。
