# 错误码与前端处置

## 段位

| 段 | 域 | 段 | 域 |
|---|---|---|---|
| 1xxx | 内部（未分类 / panic 兜底） | 5xxx | 技能 · 插件 · 能力不支持 |
| 2xxx | 启动 · 装配 | 6xxx | 会话 |
| 3xxx | 引擎进程 · 协议 | 7xxx | 入参 · 鉴权 |
| 4xxx | 模型 · 凭据 | 8xxx | 文件 · 路径 |

## 前端处置（哪个码给什么交互）

这是本文档最重要的一节：**同一个码在整个界面里必须给同一种反应**。

| 码 | 界面应该做什么 |
|---|---|
| `1001` | 轻提示「出了点问题」，同时把详情写进日志抽屉。不弹窗。 |
| `2001` | 整屏 `StartupError`，带「重试」与「打开日志」。这是启动失败，别的都不可用。 |
| `3001` 引擎没找到 / 没跑 | 输入框禁用 + 一段横幅（一句话 + 可复制安装命令 + 「重新检测」）。**不弹窗**。 |
| `3002` 引擎忙（正在跑一轮） | 轻提示「这一轮还没跑完」+ 禁用发送。 |
| `3003` 命令超时 | loading 结束 + 轻提示「这次操作超时」，不清空用户输入。 |
| `3004` 帧解析失败 | 页头连接灯变红 + 轻提示，提示引擎版本可能不兼容。 |
| `3006` 引擎不支持该能力 | **不该出现**。出现即说明前端没查 `caps`——记日志，界面静默隐藏入口。 |
| `4001` 模型不存在 | 下拉框标红该行，提示「这个模型引擎不认识，检查 models 配置」。 |
| `4002` 服务商已存在 | 表单内联错误，不发轻提示。 |
| `4003` 登录失败 | 登录卡片内联错误 + 原文；不关闭卡片。 |
| `5004` 插件命令失败 | 该行标红 + 原文输出抽屉；列表不被清空。 |
| `5002` 技能文件不可解析 | 该行标灰 + 悬停显示原因；不要整页失败。 |
| `5003` 技能目录不可写 | 轻提示 + 「以只读方式查看」；开关拨回原位。 |
| `6001` 会话文件损坏 | 该行标灰，可删除；不要整页失败。 |
| `6002` 会话正被占用 | 轻提示「这个会话正在别的窗口里跑」，禁用删除/改名。 |
| `7001` 入参不合法 | 表单内联错误。 |
| `7002` 令牌无效 | 重连一次；仍失败则提示「请重启应用」。 |
| `8001` 路径不存在 | 轻提示 + 「重新选择」。 |
| `8002` 文件被占用 | 轻提示「有进程正在用这个文件」，给「打开所在目录」。 |
| `8003` 网络请求失败 | 轻提示 + 「检查网络或代理」。 |
| `8004` 插件安装失败 | 该行标红 + 原文输出抽屉；列表不被清空。 |

三条纪律：

1. **错误必须带下一步**。不是「失败了」，而是「连不上引擎：检查是否装好了」。
2. **`detail` 只进日志，不进界面**。界面上永远只显示 `message`。
3. **不要用一个泛化码兜所有失败**。宁可加一个码，也不要让用户面对「操作失败」。

## 码表

| 码 | 常量 | 含义 | 用户看到的下一步 |
|---|---|---|---|
| 1001 | `CodeInternal` | 未分类内部错误 | 出了点问题，已记进日志 |
| 2001 | `CodeStartup` | 启动装配失败 | 重启应用；仍失败就看日志 |
| 2002 | `CodeDataDir` | 数据目录不可写 | 换一个可写目录或检查磁盘 |
| 3001 | `CodeEngineDown` | 没找到引擎 / 引擎没跑 | 先装引擎（命令已给），或点重新检测 |
| 3002 | `CodeEngineBusy` | 引擎忙（正在跑一轮） | 等这一轮结束 |
| 3003 | `CodeEngineTimeout` | 命令超时 | 稍后重试 |
| 3004 | `CodeProtocol` | 帧解析失败 | 引擎版本可能不兼容 |
| 3006 | `CodeEngineUnsupported` | 引擎不支持该能力 | —（前端应已隐藏） |
| 4001 | `CodeModelInvalid` | 模型不存在 | 检查模型配置 |
| 4002 | `CodeProviderExists` | 服务商已存在 | 换个名字 |
| 4003 | `CodeLoginFailed` | 登录失败 | 看原因原文，或去终端登录 |
| 5002 | `CodeSkillInvalid` | 技能文件不可解析 | 修 frontmatter |
| 5003 | `CodeSkillReadOnly` | 技能目录不可写（插件/工作区） | 只读查看 |
| 5004 | `CodePluginFailed` | 插件命令失败 | 看原文输出 |
| 6001 | `CodeSessionInvalid` | 会话文件损坏 | 可删除 |
| 6002 | `CodeSessionBusy` | 会话被占用 | 等它跑完 |
| 7001 | `CodeBadRequest` | 入参不合法 | 按提示改 |
| 7002 | `CodeUnauthorized` | 令牌无效 | 重启应用 |
| 8001 | `CodeNotFound` | 路径不存在 | 重新选择 |
| 8002 | `CodeFileBusy` | 文件被占用 | 关掉占用它的程序 |
| 8003 | `CodeNetwork` | 网络请求失败 | 检查网络或代理 |
| 8004 | `CodeInstallFailed` | 插件安装 / 卸载失败（跑引擎 CLI 失败） | 看原文输出 |
