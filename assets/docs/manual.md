# 内置手册

OhMyPiDesktop 是 **omp（OhMyPi）与 pi（Pi）** 两个终端 coding agent 的桌面工作台。
它不自己实现 Agent：工具、压缩、重试、缓存、子代理、MCP 全由引擎自己负责，
这里只把引擎吐出的事件翻译成能看的界面，把它暴露的操作变成能点的控件。

## 第一次打开

1. **装引擎**（这步应用不做）。在终端里装好其中一个或两个：

   ```powershell
   # omp
   irm https://omp.sh/install.ps1 | iex

   # pi
   npm i -g @earendil-works/pi-coding-agent
   ```

   装完重开终端让 PATH 生效，回到应用点「设置 → 环境 → 重新检测」。
   应用只探测、不下载、不改 PATH、不写注册表。

2. **配模型**：模型页 → 新增服务商，填接口地址、密钥、至少一个模型 id。
   两个引擎的配置文件不同（omp 写 `models.yml`，pi 写 `models.json`），
   所以模型页顶部跟着当前引擎走。需要 OAuth 的服务商（仅 omp）在「登录」那一组里点一下。

3. **选目录**：对话页右上角的文件夹按钮，选一个项目目录。
   这个目录下的 `AGENTS.md`、`.omp/skills`（或 `.pi/skills`）、git 仓库都会对引擎生效。

4. **开聊**：输入框里说话，Enter 发送。

## 两个引擎

输入框上方有一个 `omp | pi` 的分段控件，**只有一个引擎装好时不显示**。

- 切引擎**不切目录、不切会话**。切过去之后会开一个新会话——
  两个引擎的会话文件不是能互换接着聊的东西。
- 引擎不支持的功能**整块不渲染**，不显示灰按钮：
  pi 下没有子代理面板、没有 OAuth 登录、没有排队条目的移除。
- 标题栏右上角只有一个连接灯：它是「后端服务连上了没」，不是「引擎在跑没跑」。

## 对话页

| 你看到的 | 意思 |
|---|---|
| 徽章 `you` | 你发出去的话 |
| 徽章 `assistant` + 左侧竖线 | 助手的回答面板；一轮里思考、正文、工具卡按发生顺序排 |
| 灰色块「思考」 | 模型的思考过程，点开看，正文出现后自动收起 |
| 工具卡 | 它执行的命令 / 读的文件；点开看参数与输出 |
| 输入框上方的状态条 | 扩展设的状态（例如后台任务进度） |
| 弹出卡片 | 引擎在问你问题（确认 / 选择 / 填空） |

**正在回答时**：Enter = 插话（马上进入这一轮），Shift+Enter = 换行，
Alt+Enter = 排队（等这一轮结束再说）。「停止」会同时停掉当前轮与排队。

**斜杠命令**：输入 `/` 会列出引擎报上来的命令（含插件与技能带来的）。

**右栏子代理**（仅 omp）：模型自己调 `task` 工具拉起的子代理会出现在这里。
可以看到进度、当前工具、花费，能插一句话或直接掐掉它。这里不是编排器——
omp 没有「安排一个团队」的 RPC。

## 工作区页

三栏：左边文件树，中间改动清单与提交框，右边差异。

- 文件树只读。写文件是助手的事，界面不该有第二个写入口。
- 「改动」按已暂存 / 未暂存分组；点一行看它的差异。
- 点「加入」把文件放进待提交区，写一句提交信息再提交。
- 「丢弃」是不可撤销的，会二次确认。
- 有未完成的合并 / 变基时，顶部横幅给「继续 / 中止」。
- 分支列表可以切换、新建。

**没装 Git** 或 **目录不是仓库** 时，页面给出原因与「初始化仓库」，不显示空表格。

## 会话页

列出**当前引擎**会话目录里的全部会话，包括你在终端里聊的那些。
点一条就继续聊；可以改名、删除。删除会连会话文件与子代理记录一起删掉，不能恢复。

## 模型页

三块，分界线是「我们能不能改」：

- **服务商**：能从界面改的。密钥打码显示，不改就不覆盖已存的。
- **登录**（仅 omp）：发起 OAuth，授权链接会挂在对话页顶部可复制。
- **可用模型**：只读，来自引擎自己的 `get_available_models`。

## 技能页

按来源分组：工作区 / 用户 / 托管 / 插件。开关只对用户目录里的那份可用。

- omp 的开关改 `SKILL.md` 的 `enabled` 字段。
- pi 没有这个开关，它用 `disable-model-invocation`：关掉表示「不让模型自己用」，
  仍然可以 `/skill:name` 显式调用。

## 插件页

omp 走 `omp plugin`，pi 走 `pi install / remove`。装完要重启引擎才生效。

## 用量页

token 与花费，全部来自引擎自己写的会话文件——**不另建一张账单表**。
两个引擎的用量合在一起算，因为那是同一笔钱。

## 设置页

| 节 | 内容 |
|---|---|
| 外观 | 主题、字号缩放、减少动效 |
| 环境 | 每个引擎一张卡：探测结果、版本、显式路径、落盘位置、重启。缺引擎时给安装命令原文 |
| 工作区 | 当前目录、最近目录、切换 |
| 关于 | 版本、日志、数据目录 |

**没有「安装」按钮。** 装引擎是用户的事，我们只探测和给命令。
